## Propósito del laboratorio 
En este laboratio se estara probando y documentando la seguridad de la zona desmilitarizada (DMZ), a traves de los equipos de red y como firewall principal un equipo Fortigate. Tambien incluira la funcionalidad de los JumpServer para asegurar una seguridad de los servidores principales a traves de RDP y la aplicacion de VPN entre Proveedor y Usuario.
